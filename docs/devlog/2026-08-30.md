## `#タグ` を書いたとおりに表示する

### やったこと
- レビューで判断待ちにしていた「`#タグ` の描画で先頭の `#` が落ちる」を回収した
- `syntax.ts` の link ノードに `tag?: true` を足した。タグ由来かどうかを覚えるだけで、`title`(= リンク先)は `[タグ]` と完全に同じ
- `LineRenderer` は `tag` が立っていれば `#タグ` と表示し、`class="tag"` を付ける。CSS で少しだけ色を弱めた
- テストを更新+追加: `#タグ` に印が付くこと、`[タグ]` には付かないこと、混在行
- E2E: `#日記` と `[日記]` が同じ href に解決される / 表示は `#日記` と `日記` で書いたとおり / タグをクリックしてページに辿れる / タグからもバックリンクが出る

### 詰まった点・気づき
- 別ノート型(`{type:"tag"}`)にする案もあったが、そうすると `links.ts` の `extractLinkTitles` や将来のリンク処理がすべて2分岐になる。「リンクであることは同じ、見た目だけ違う」という実態に合わせて link ノードの任意フィールドにした。おかげでサーバ側は1行も変えずに済んだ
- `tag?: true`(省略可)にしたので、`[タグ]` 側のノードは以前と同じ形のまま。既存テストの deep-equal が壊れず、差分が小さく収まった

### 関連ADR / コミット
- なし(SPEC.md の「`#タグ` は `[タグ]` と同じ扱い」を満たしたままの表示改善)

## RelatedPages をコンポーネントに切り出す

### やったこと
- PageView 内にあった `RefList` を `src/client/components/RelatedPages.tsx` に移した。SPEC.md のディレクトリ構成が挙げている `components/RelatedPages` に合わせる整理
- 切り出す単位は `RefList`(1リスト)ではなく `RelatedPages`(バックリンク + 2ホップ)にした。SPEC の機能一覧が「ページ下部: バックリンク一覧 + 2ホップ先」と1つのまとまりとして書いているため。`RefList` はその内部ヘルパとして非公開のまま残した
- PageView 側は `<RelatedPages backlinks={...} twoHop={...} />` の1行になり、`PageRef` の import も不要になった
- 挙動は不変。E2E で A→B→C のリンク構造を作り、片側だけ存在するとき見出しが1つしか出ないこと・0件のセクションが出ないこと・関連リンクから遷移できることを確認

### 詰まった点・気づき
- E2E を書いていて C ページで `.content` を待ち続けてタイムアウトした。原因は本文がタイトル行だけのページを編集モードで開く既存仕様(作りたてページをすぐ書き始められるようにするための挙動)で、リファクタの影響ではなかった。テスト側で C に本文を持たせて解決

### 関連ADR / コミット
- なし(挙動を変えないリファクタリング)

## 履歴に「差分 / 本文」トグルを足す

### やったこと
- レビューの判断待ち最後の1件。SPEC.md の「選択で本文表示 + 現在との行 diff」のうち、本文表示にあたるものが無かった
- 右ペインに「差分 / 本文」のトグルを追加した。既定は差分のまま。本文側は `LineRenderer` を通すので、PageView と同じ描画でその版が見られる
- E2E: 既定が差分であること / 本文に切り替えると `[リンク先]` `#タグ` `[* 強調]` `code:ts` がすべて描画されること / 生の記法文字列が残らないこと / 差分に戻せること / 本文モードからも復元できること

### 詰まった点・気づき
- 「本文が見えない」問題の本体は、diff が現在と混ざることではなく **`<pre>` で生テキストを出していること** だった。`[/files/....png]` が画像ではなく長い文字列として出るので、画像を貼ったページの昔の姿は事実上確認できなかった。トグルを足す判断はこちらが決め手
- 2ペイン併置ではなくトグルにしたのは、履歴画面の主目的が差分で、本文は「たまに昔の見た目を確かめる」用途だから。縦に伸ばさずに済む

### 関連ADR / コミット
- なし(SPEC.md 記載の「本文表示」の実装)
